# 공생의 알고리즘 AI

NCPMS 병해충 관측자료, 천적 문헌 근거, 현장 조건 및 사용자 입력 비용을 분리하여 검토하는 농업 의사결정 지원 프로토타입입니다.

서비스: https://app.gongsaeng-ai.com

이 저장소는 기존 Streamlit 프로젝트에 현재 운영 중인 Next.js 프런트엔드와 FastAPI 백엔드를 추가한 것입니다. GitHub 업로드 자체가 운영 서버를 재시작하거나 Cloudflare Tunnel 배포를 변경하지는 않습니다.

## Kiln 모델 안내 (연동 미완료)

사용자가 전달한 주최 측 공지에 맞춰 모델 식별자를 `Qwen3-32B`로 지정합니다. 이번 검색에서 기존 Kiln 호출 코드와 이전 모델 설정은 발견되지 않았습니다. 환경변수는 `KILN_MODEL=Qwen3-32B`이며, 미설정 시에도 같은 값을 사용합니다. 다른 모델 값은 빌드를 중단합니다.

프런트엔드 빌드 환경 또는 `frontend/.env.local`에 이 **비밀이 아닌 모델 식별자만** 설정할 수 있습니다. Next.js 설정을 통해 화면 안내에 반영되므로 변경 시 재빌드해야 합니다. 실제 환경파일은 커밋하지 않습니다.

화면 상태: **Kiln 팀 계정 및 API 접근권한 대기 중**. 현재 공식 접속정보와 인증을 이용한 호출 어댑터는 미구현입니다. 모델명 설정만으로 연동이 완료되지 않으며, 가짜 응답·토큰 수·에너지 사용량·호출 기록을 생성하지 않습니다. API 키와 접속정보를 추측해 추가하지 않습니다.

### Kiln 연결 준비와 후속 연결 절차

**실제 Kiln 연동은 미완료입니다.** 백엔드 `backend/kiln.py`는 환경설정 로더, 내부 입력·결과 인터페이스, STOP 처리, 오류·시간초과의 비밀정보 없는 요약, 향후 실제 호출용 감사 기록 형식만 제공합니다. API 요청 경로·인증 헤더·요청 JSON은 구현하지 않았으며 다른 AI로 대체하지 않습니다. 구매 승인·결제 실행은 연결하지 않았습니다.

- 환경변수: `KILN_API_BASE_URL`, `KILN_API_KEY`, `KILN_MODEL`, `KILN_API_TIMEOUT_SECONDS`.
- 모델 기본값: `Qwen3-32B`. 시간 제한 기본값: 30초(내부 설정값이며 공식 규격을 의미하지 않습니다). 유효하지 않은 값은 호출을 차단합니다.
- `GET /api/kiln/status`: 설정 여부, 모델, 실제 호출 가능 여부, 마지막 성공 여부와 안전한 오류 요약만 반환합니다. 주소·키·키 일부를 반환하지 않습니다.
- 설정 없으면 `STOP / KILN_NOT_CONFIGURED`: “Kiln 팀 계정 및 API 접근권한을 기다리고 있습니다.”
- 설정을 모두 입력해도 현재는 `KILN_PROTOCOL_NOT_IMPLEMENTED`, `callable: false`입니다. 실제 호출이 없으므로 마지막 성공·오류는 `null`입니다.
- 감사 로그는 구조만 준비되어 있으며 현재 기록을 만들지 않습니다. 공식 연동 구현 시 실제 호출에 한해서 단계·목적·모델·제공된 토큰 사용량·안전하게 정규화한 결정 요약·성공 여부·시각·ID를 기록해야 합니다. 토큰 누락은 “제공되지 않음”이며 에너지값·프롬프트 전문·개인정보·비밀값은 저장하지 않습니다.

공식 문서와 계정을 받은 후:

1. 주최 측에서 팀 계정과 API 키를 받습니다.
2. 공식 문서에서 접속 주소·인증 헤더·요청·응답 형식을 확인합니다. **먼저 `KilnTransport`의 TODO를 실제 규격에 맞게 구현**하고 시간 제한, 응답·토큰 매핑, 비밀정보 제거, 실제 호출 감사 저장 및 상태 갱신을 검증합니다. 현재는 환경변수만 넣어도 연결되지 않습니다.
3. Git에서 제외된 로컬 `backend/.env`에 네 환경변수를 입력합니다. 키를 프런트엔드 환경파일에 넣지 않습니다.
4. `backend` 디렉터리에서 기존 가상환경을 활성화한 후 `python -m uvicorn main:app --host 127.0.0.1 --port 8000 --env-file .env`로 FastAPI를 재시작합니다. 환경파일은 자동으로 읽히지 않으므로 이 옵션 또는 안전한 서버 환경변수 주입이 필요합니다. 자동 복구 실행기도 향후 동일한 주입 설정이 필요합니다.
5. `GET /api/kiln/status`로 설정 여부를 확인합니다. 설정 여부만으로 접속 성공을 판단하지 않습니다.
6. 구현·검증한 어댑터로 최소 요청 1건의 실제 `Qwen3-32B` 호출을 시험합니다(현재 실행 가능한 호출 API는 없습니다).
7. 실제 응답 및 제공된 토큰 사용량의 감사 기록을 확인합니다.
8. 정상·차단 구매 시나리오를 다시 검증합니다. Kiln 오류·시간초과 시 승인·결제하지 않는 원칙을 유지합니다.

오프라인 준비 테스트: 프로젝트 루트에서 `python -m unittest backend.test_kiln`. 실제 API를 호출하지 않으며 테스트용 표식·mock은 자동 테스트에만 존재합니다.

## 격리된 구매 승인 에이전트 준비화면

- 경로: `/agent-finance`. 대규모 연구분석 콘솔의 **구매 승인 에이전트 준비화면** 버튼으로 이동합니다. 선택한 작물·병해충·지역만 전달하며 나머지 농업 근거는 검증된 원본 연결 전까지 자료 없음입니다.
- 연구분석 콘솔은 기존 연구 결과와 읽기 전용 `GET /api/kiln/status`만 표시합니다. 페이지 로드·새로고침·선택 변경·그래프 조회는 Kiln을 호출하지 않습니다.
- 향후 실제 `Qwen3-32B` 호출 위치는 **이 화면의 구매 제안 생성 동작뿐**입니다. 내부 `POST /api/agent-finance/review`는 현재 일반 코드 검사와 감사 기록만 수행하고 Kiln·결제·블록체인을 호출하지 않습니다. 상태 조회도 추론이나 토큰 소비를 발생시키지 않습니다.
- AI 역할은 공식 규격 연결 후 구조화된 제안을 만드는 것까지입니다. 일반 코드는 수수료 포함 예산·1회 한도, 판매처·품목 허용 목록, 기한, 검증된 천적 직접근거, 사람 승인, STOP을 검사해야 합니다. 미확인 항목은 통과로 취급하지 않습니다. 상대위험을 실제 밀도·구매 필요성으로 바꾸지 않습니다.
- 현재 모든 결과는 STOP이며 실제 제안·잔여 예산·거래 해시는 생성하지 않습니다. 승인 버튼도 검증된 제안이 없으면 차단합니다. 자동 구매 금지 설정을 해제해도 실제 실행은 비활성화되며 사람 승인 없는 실행은 항상 금지됩니다.
- 정상/예산 초과/미승인 판매처 데모는 명시된 **일반 코드 규칙 검사용 입력**입니다. 정상 데모도 미연결 상태를 반환합니다. 가짜 AI 응답이나 테스트넷 성공을 쓰지 않습니다.
- 사용자 행동 감사 기록은 `tmp/runtime/finance-audit.sqlite3`에 저장합니다(Git 제외, 조회 공개 API 없음). 예산·한도·수수료·기한·안전 설정·목록의 개수와 SHA-256 해시·조건별 검사·행동·시각·ID를 보관합니다. 자유입력 원문, 프롬프트, 개인정보, API 키는 저장하지 않습니다. Kiln 호출 여부는 아니오, 횟수는 0, 토큰은 제공되지 않음, 블록체인은 없음입니다. **Kiln 실제 호출 감사 기록과 다른 사용자 행동 기록**입니다.
- STOP/거절 상태는 세션 ID별로 서버에 유지되고 늦게 도착한 화면 응답도 무시합니다. 화면 최근 기록은 해당 방문의 최대 20건입니다. 로컬 DB는 최대 10,000건에서 추가 처리를 차단합니다. 운영 이관 전 인증·사용자별 접근 제어·보관 정책·레이트 제한이 필요합니다.
- 테스트넷은 `지정 테스트넷 정보 대기 중`입니다. `TestnetTransport`는 기록 요청/receipt 역할만 정의합니다. `approval_record_hash`는 승인 기록의 내부 해시 도우미이며 트랜잭션 해시가 아닙니다. 네트워크·서명·지갑·자금 사용은 구현하지 않았습니다.

### 공식 문서·계정을 받은 후 남은 연결

1. 위 네 Kiln 환경변수와 공식 접속·인증·요청·응답·토큰·오류 규격을 확인하고 `backend/kiln.py`의 TODO를 구현합니다. 키는 서버의 비공개 환경파일에만 입력하며 기존 안내대로 FastAPI를 `--env-file .env`로 재시작합니다.
2. `backend/agent_finance.py`의 generate 경로에 검증된 농업 근거·공급처 가격 원본을 연결합니다. 일반 코드 사전 검사 후에만 실제 Kiln 요청을 보내고 응답 제안도 다시 검사합니다. 연구 콘솔에는 호출을 연결하지 않습니다.
3. 실제 제안을 변경 불가능한 ID에 묶고, 인증된 사람의 승인·거절·STOP, 멱등성, 실행 직전 STOP 재검사를 구현합니다. 화면의 승인 클릭만으로 실행하도록 바꾸지 않습니다.
4. 주최 측 공식 devnet/testnet·계정·서명·기록 규격을 받아 `TestnetTransport`와 실제 receipt 검증을 구현합니다. 최종 승인 전 호출 금지, 실패·시간초과 시 STOP입니다.
5. 실호출 성공/실패에 한해서 실제 토큰·안전한 요약·감사 ID를 기록하고 연결 검증 상태를 갱신합니다. 공식 최소 요청 1건을 확인한 뒤 정상·차단 시나리오를 재검증합니다.

준비화면 테스트: `python -m unittest backend.test_agent_finance backend.test_kiln`, `node --test frontend/tests/agent-finance.test.cjs frontend/tests/kiln-model.test.cjs`.

**현재 Kiln·테스트넷 연동은 미완료이며 실제 금융서비스가 아닙니다.** 구매 조언·자금 집행 서비스가 아닌 연구용 준비화면입니다.

## 현재 핵심 방향 — 노지 분석과 경관관리

운영 연결·자동 복구: [RUNTIME_RECOVERY.md](RUNTIME_RECOVERY.md). 현재 사용자 로그인 후 앱 자동 실행과 프로세스 종료 복구를 지원합니다. 노트북 전원 꺼짐·절전 중 제공하려면 별도 상시 서버가 필요합니다.

- 핵심 트랙: NCPMS 예찰자료 → 기상 배경의 탐색적 연관성 → 단기 시공간 패턴 → 실제 밀도·경관조사 → 천적 보호 경관관리 검토.
- 기존 190개 병해충, 위험도, 조사회차 그래프, 지역 비교, 2027 연구용 전망, 기상 관측 및 천적 추천은 유지합니다.
- 스마트팜은 별도 **스마트팜 확장 연구 트랙**입니다. 2015~2024년 238농가·651작기 자료는 작기·시설환경 맥락이며 해충 밀도자료가 아닙니다. NCPMS로 시설 해충 밀도·방사밀도·최적 시점을 추정하거나 점수를 합산하지 않습니다.
- 천적 구입·방사 경제성은 별도의 사용자 가정 시나리오입니다. 노지 경관관리·스마트팜과 결과를 합산하지 않으며, 긍정적 경제성만으로 실제 도입을 확정하지 않습니다.
- NCPMS 2024~2026은 단기 패턴입니다. KMA 장기자료는 기상 배경·장기 기후경향 검토용이며 관계는 탐색적 연관성에 한정합니다. **장기 병해충 자료 부족으로 기후변화 인과효과는 판정하지 않음**.

### 실제 밀도와 경관 입력

`POST /api/landscape-review`는 작물·병해충·지역을 받아 기존 서버의 2026 NCPMS 상대위험도와 조사회차 패턴·연결 천적을 조회합니다. 사용자가 보낸 위험점수나 효과율은 받지 않습니다.

노지 재배유형, 가장자리 식생, 꽃자원, 초생대·피난처, 수림대·울타리, 토지이용, 예초·제초, 비선택성 살충제 사용, 해충 밀도조사 및 천적 관찰 여부를 입력합니다. 실제 조사 밀도·방법·단위·조사일을 별도로 받으며 미확인 상태와 실제 관측 0을 구분합니다. 조건 변경 시 입력을 초기화하고 요청 실패에는 제한시간과 재시도를 적용합니다. 입력은 검토를 위해 서버로 전송되며 저장하지 않습니다.

상대위험도를 마리 수·피해주율·경제적 피해수준으로 변환하지 않습니다. 포장명, 조사 면적·주수, 천적 관찰 수와 마지막 약제 처리일도 별도로 입력합니다. 미입력은 0이 아닙니다.

경제적 기준 A는 값·단위·작물·병해충·출처·적용 지역 또는 재배조건을 받습니다. 출처·단위가 없으면 `출처 확인 필요`이며, 출처를 입력해도 공식 원문 검증을 완료한 것으로 표시하지 않습니다. 조건과 밀도 단위가 일치할 때만 사용자 입력 기준과 수치 비교합니다.

방식 B는 `EIL = C / (V × I × D × K)`입니다. C(방제비용), V(작물 단위가치), I(개체당 손상), D(손상당 수량손실), K(방제효율)의 값과 단위를 모두 입력해야 합니다. 기본값은 없습니다. C는 원/m²·원/ha·원/주·원/잎, V는 원/kg, I·D는 cm²/마리 + kg/cm² 또는 피해단위/마리 + kg/피해단위, K는 0 초과 1 이하 비율을 지원합니다. 단위 불일치·누락이면 `EIL 계산 근거 부족`입니다. 다른 단위로 임의 환산하지 않습니다.

계산 결과는 사용자 입력 시나리오이며 공식 기준, 실제 피해율 또는 방제 명령이 아닙니다. 선형 손상·손실 가정과 현장 검증이 필요하며 행동시점 기준(ET)을 계산하지 않습니다. 공식 기준 원장은 현재 미확보입니다. [EIL 이론 출처: University of Minnesota, Pedigo](https://ipmworld.umn.edu/pedigo).

### 판단 상태와 근거

- `경관조사 우선`: 경관조건 부족.
- `근거자료 부족`: 실제 밀도·조사 방법·단위·경제적 기준 부족 또는 연결 근거 없음.
- `보전관리 조건부 검토`: 필수 입력과 유리한 서식처 조건이 있으며 일반 근거만 연결되고 직접효과는 미확인.
- `현장 실증 후보`: 직접근거·현장조건 연결 후에도 현장 효과 검증 필요. 현재 국내 직접 처리·대조 원장이 없어 실제 응답에서는 이 상태로 승격하지 않습니다.

등급은 A(동일 작물·해충·환경의 공식 처리·대조 실험), B(공식·동료심사 조건부), C(현장 검증이 필요한 간접 근거), 자료 없음(현재 조건 연결 근거 없음)입니다. 천적 방사 시험의 기존 A등급을 경관관리 A등급으로 전용하지 않습니다. 현재 연결은 진딧물과 무당벌레·풀잠자리·꽃등에 기능군에 대한 일반 C근거로 제한됩니다. 실제 식생·꽃·피난처·약제 이력에 따라 검토목록을 달리하고 모든 작물·병해충에 동일 목록을 권고하지 않습니다.

검증한 출처:

- [USDA NRCS, Common Beneficial Insects and their Habitat (2014)](https://www.nrcs.usda.gov/plantmaterials/txpmctn12248.pdf): 국외 일반 서식처·먹이 지침. 국내 동일 작물·천적종 직접시험 아님.
- [Karp et al. (2018), PNAS](https://pmc.ncbi.nlm.nih.gov/articles/PMC6099893/), DOI `10.1073/pnas.1800042115`: 경관에 대한 해충·천적 반응의 이질성. 현장 효과 보장 아님.

꽃자원·비경작 식생은 일부 해충에도 유리할 수 있습니다. 정량 폭·면적·식물종·예초 간격·효과율은 생성하지 않습니다. 국내 동일 조건 처리·대조, 천적 동정, 약제 이력, 공식 경제적 피해기준과 조사 단위 자료가 추가로 필요합니다. 결과는 확정 진단이나 자동 작업명령이 아닙니다.

## 주요 기능과 해석 원칙

- NCPMS 2024·2025·2026 관측자료 기반 상대 위험도, 조사회차별 그래프, 지역·연도 비교. 관측값 0과 자료 부재를 구분합니다.
- 천적 추천, 문헌 링크, 근거 등급 및 동일 작물·병해충·재배환경의 직접근거 여부를 구분합니다. PubMed 문헌이 있어도 직접근거와 경제성이 확보되었다는 뜻은 아닙니다.
- 스마트팜 사례와 기상 관측은 별도 참고자료입니다. NCPMS 위험도를 임의 가산하거나 다른 농가의 수익을 사용자 농가의 수익으로 간주하지 않습니다.
- 사용자가 입력한 현장 조건·비용과 검증된 근거로 경제성 및 도입 가능성을 검토합니다. 필수자료가 없으면 최종 판정은 '자료 부족'으로 유지합니다.
- 지역 CSV, 스마트팜, 기상자료 요청은 제한시간 후 실패·자료 없음·다시 시도 상태를 표시하며 가짜 관측값을 만들지 않습니다.
- 2027 전망은 과거 자료 기반 연구용 추정으로 미래의 실제 발생량·확률이나 기상을 확정하지 않습니다.

본 서비스는 확정 진단 또는 자동 방제 명령을 제공하는 시스템이 아닙니다. 농약 등록사항, 천적 방사 조건 및 현장 안전은 공식 지침과 전문가 확인이 필요합니다. FuriosaAI·Bricksum 연동을 구현된 기능으로 제공하지 않습니다.

## 실행 환경

검증 환경은 Windows, Node.js 24.19.0, Python 3.13.12입니다. 프런트엔드 잠금파일 기준 Next.js 16.3.0, TypeScript 5.9.3을 사용합니다. 다른 버전 조합은 별도 검증하지 않았습니다. `npm ci`로 잠금파일을 사용하십시오.

### 백엔드

저장소 루트에서 다음 명령을 실행합니다. Python 3.13 및 uv가 설치되어 있어야 합니다.

```powershell
cd backend
uv venv --python 3.13
.\.venv\Scripts\Activate.ps1
uv pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

최신 API 의존성은 반드시 `backend/requirements.txt`를 사용합니다. 루트의 `requirements.txt`는 과거 Streamlit용입니다. `/api/health`로 상태를 확인할 수 있습니다.

### 프런트엔드

다른 터미널에서 저장소 루트 기준으로 실행합니다.

```powershell
cd frontend
npm ci
npm run dev
```

프로덕션 실행:

```powershell
cd frontend
npm run build
npm run start -- --hostname 127.0.0.1 --port 3000
```

프런트엔드는 기본적으로 `http://127.0.0.1:8000`의 백엔드로 `/api` 요청을 전달합니다. 운영 중인 `.next`를 덮어써 빌드하지 말고, 별도 검증본에서 빌드한 후 운영 절차에 따라 전환하십시오. Cloudflare Tunnel 인증정보는 저장소에 포함하지 않습니다.

## 환경변수

`.env.example`은 실제 코드가 읽는 이름만 빈 값으로 제공합니다. 루트의 예제 파일이 자동으로 모든 프로세스에 로드되는 것은 아닙니다. Next.js용 값은 필요할 때 `frontend/.env.local` 또는 프로세스 환경에 설정하고, Python용 값은 백엔드 프로세스 환경에 설정하십시오. 기본값을 사용할 때는 URL 변수를 빈 문자열로 설정하지 말고 생략하십시오.

| 이름 | 사용처 |
| --- | --- |
| `BACKEND_API_URL` | Next.js 서버 프록시·초기 데이터. 기본 `http://127.0.0.1:8000` |
| `INTERNAL_FRONTEND_URL` | 서버 내부 부트스트랩. 기본 `http://127.0.0.1:3000` |
| `CORS_ALLOWED_ORIGINS` | FastAPI 추가 허용 출처, 쉼표 구분 |
| `DATA_GO_KR_KEY` | 포함된 NCPMS 수집 스크립트 및 공공데이터 키 설정 상태 확인 |
| `NONGSARO_API_KEY`, `Nongsaro` | 농사로 키 설정 상태 확인용 별칭 |
| `PSIS_API_KEY` | 농약 API 키 설정 상태 확인 |
| `NEXT_PUBLIC_API_URL` | 보존된 과거 페이지 백업에서만 사용; 현재 페이지 설정 아님 |

포함된 스냅샷으로 기본 앱을 실행하는 데 수집용 API 키는 필요하지 않습니다. 키가 설정되었다는 표시만으로 실시간 API 연동이 완료된 것은 아닙니다. 실제 키, 토큰, 비밀번호 및 개인키는 커밋하지 마십시오.
